# Background video

Drop your own looping background clip here:

- `ambient.webm` (preferred, smaller)
- `ambient.mp4` (fallback)

**Tips**

- Keep it under ~5 MB for fast loads
- 10–20 seconds, seamless loop
- Abstract motion (gradients, particles, code, city bokeh) works best
- No audio needed (plays muted)

Free sources: [Mixkit](https://mixkit.co/free-stock-video/abstract/), [Coverr](https://coverr.co/)

If no file is present, the site uses a **canvas aurora animation** automatically.
